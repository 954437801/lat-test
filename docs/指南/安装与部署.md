# 安装与部署

## 依赖

### 运行

- python3 ≥ 3.6（仅标准库）。自检：`python3 --version`
- 测试机（Linux）缺 python3 时：`apt install python3`

### 构建

- `build/build.sh` 硬性要求：`gcc`、`ar`、`x86_64-w64-mingw32-gcc`、
  `i686-w64-mingw32-gcc` 与对应 `-ar`。
  安装：`sudo apt-get install -y gcc-mingw-w64-x86-64 gcc-mingw-w64-i686`
- `gcc -m32`（i386 形态）需 `gcc-multilib` / `libc6-dev-i386`。
- loongarch64 交叉工具链（`loongarch64-linux-gnu-gcc`）为**可选**（仅 cfloat 组的
  loongarch64 形态需要）：缺则 `forms_of()` 自动跳过 loongarch64 形态，不 fail 整构。
- openssl/openssl11 探针（构建机 WSL）：
  `apt install libssl-dev libssl-dev:i386 gcc-multilib libc6-dev-i386
  zlib1g-dev zlib1g-dev:i386 libzstd-dev libzstd-dev:i386`
  （Debian libcrypto.a 静态链需补 zlib/zstd）。

### 第三方源码

- sfloat 组依赖 Berkeley SoftFloat-3e（外部源，不入库）。首次构建前取回：

  ```bash
  bash third_party/get_softfloat.sh
  ```

  详见 [third_party/README.md](../../third_party/README.md)。

## 部署动作（目标机第一次）

1. 整目录拷贝（含 `bin/`、`isbench.py`、`app/`、`docs/`）。
2. `python3 --version` 自检；缺则安装（`apt install python3`）。
3. （可选）分析机起 `serve`；测试机 `run` 加 `--push` 或 export `ISBENCH_PUSH`。

> 测物 = 交付物：同一份 `dist` 推到各机，真机上一律不重编（详见
> [../规划/验证记录.md](../规划/验证记录.md)）。
